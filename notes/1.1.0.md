- **Your project's files, one folder at a time.** Explorer shows the working tree of the open project, like the file list of a code editor.
- **Press a file to look at it everywhere.** Pressing a file points the canvas at it, so Paper, Source, Notes, Diff and the rest move to that file together.
- **Look, never touch.** Explorer cannot create, rename, move or delete anything, and it does not hand out file contents.
