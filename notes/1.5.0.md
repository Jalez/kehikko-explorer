Kind: feature

- **Drag a file out of the tree.** Drag a file or folder from the tree and drop it on a module that opens files, and it opens there. Dropped into a terminal or a text field, it types the file's path.

## For agents

- A dragged row carries the protocol's drag format for a file in a project (`fileDrag`, protocol 2.94.0): `{ project, path, kind }`, plus a `file://` uri-list and the absolute path as text. The host hands a drop across frames on to a module that declares `opens: ['file']`.
